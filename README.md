# 忘れ物もうなし！AI手荷物確認

FlutterとGoogle ML Kitを用いて開発した、AI手荷物確認アプリです。

## アプリ概要
カメラで持ち物を撮影するだけで、AIが物体を認識し、
事前に登録した持ち物セットと比較して忘れ物を確認できます。

「財布・スマホ・鍵」などの日常の持ち物確認を
簡単に行えることを目的として開発しました。

## 使用技術
・Flutter
・Dart
・Google ML Kit
・Camera Package

## 主な機能
・カメラ撮影
